## Codebase Patterns
- Unity build: `src/jacl.c` #includes all pipeline .c files + lib headers as a single translation unit
- JACL pipeline files in `src/`: plain .c with `#ifndef X_C` guards, no `#define X_IMPLEMENTATION` needed
- Lib modules in `lib/`: single-header convention with `#ifdef X_IMPLEMENTATION`
- Test files: `#include "test_helpers.h"` then `#include "../src/jacl.c"` — gets everything
- Arena allocator: zero-init `arena_t arena = {0}`, uses libc by default
- Test tracked allocator: `tracked_allocator` from `test/test_helpers.h`, plug into arena via `.allocator = tracked_allocator`
- Build system: `build.sh` with `TESTS=()` array entries formatted as `"path/test.c|name|optional_extra_cflags"`
- Compiler flags: `-Wall -Wextra -std=c99 -g`
- Implementation language is C (C99)
- Pipeline: src/value.c → src/lexer.c → src/ast.c → src/parser.c → src/bytecode.c → src/compiler.c → src/vm.c
- Private/internal functions use double-underscore prefix: `module__function_name`
- Public types use PascalCase (Token, LexResult, AstNode) or lower_t for system-level (arena_t)
- Public functions use module_verb_noun pattern (lexer_lex, arena_alloc, parser_parse)
- Constants and macros use ALL_CAPS (TOKEN_EOF, JACL_TAG_NIL)
- Test functions are `static int test_name(void)` returning 0=fail, 1=pass
- Test main() uses table-driven pattern: array of {name, fn} structs, iterates and counts pass/fail
- Memory leak check pattern: setup() -> exercise -> teardown() -> ASSERT(check_no_leaks()) -> TEST_PASS()
- Tests grouped by US-XXX story comments in the test table

- Lexer API: LexResult lexer_lex(const char* source, arena_t* arena)
- Token array always ends with TOKEN_EOF
- TOKEN_VAR payload.text points into source buffer, skips the $ prefix
- TOKEN_WORD payload.text points into source buffer
- TOKEN_STRING payload.text is arena-allocated decoded content
- TOKEN_OPERATOR handled same as TOKEN_WORD in parser

- Parser API: ParseResult parser_parse(LexResult tokens, arena_t* arena)
- ParseResult struct: AstNode** nodes, uint32_t count, uint32_t error_count
- AST node types: AST_COMMAND, AST_LIT_INT, AST_LIT_FLOAT, AST_LIT_STRING, AST_VAR_REF, AST_BLOCK, AST_INTERP_STRING, AST_ERROR
- AST_COMMAND has head (AstNode*) + args (AstNode**) + arg_count
- AstNode is a tagged union with SourcePos start/end

- Value API: JaclVal is a 64-bit tagged value in src/value.c
- Constructors: jacl_i32(val), jacl_f32(val), jacl_inline_string(ptr, len), JACL_NIL, JACL_TRUE, JACL_FALSE
- Arithmetic: jacl_add_i32, jacl_sub_i32, jacl_mul_i32, jacl_div_i32, jacl_mod_i32, jacl_neg_i32 (and _f32 variants)
- Comparison: jacl_lt_i32, jacl_gt_i32, jacl_le_i32, jacl_ge_i32 (and _f32 variants)
- Equality: jacl_eq (works across types)
- Type checks: jacl_is_i32, jacl_is_f32, jacl_is_nil, jacl_is_bool, jacl_is_inline_string, jacl_is_error
- Extraction: jacl_as_i32, jacl_as_f32, jacl_inline_string_ptr, jacl_inline_string_len

- Bytecode API: BytecodeChunk in src/bytecode.c, chunk_init, chunk_write, chunk_write_u16, chunk_add_constant
- OpCode enum: OP_CONST (+ u16 index), OP_NIL, OP_TRUE, OP_FALSE, OP_POP, OP_ADD..OP_MOD, OP_NEG, OP_EQ..OP_GE, OP_PRINT, OP_DEF_GLOBAL (+ u16), OP_GET_GLOBAL (+ u16), OP_HALT
- Bytecode arrays auto-grow via arena re-allocation (old memory left for arena to reclaim)
- Compiler API: CompileResult compiler_compile(ParseResult, arena_t*) in src/compiler.c
- CompileResult struct: BytecodeChunk chunk, uint32_t error_count
- Compiler internal: Compiler struct with chunk*, arena*, error_count
- compiler__emit_byte, compiler__emit_u16, compiler__emit_constant helpers
- Bare top-level literals are wrapped by parser as AST_COMMAND{head: literal, args: [], arg_count: 0}
- Compiler handles AST_COMMAND with arg_count==0 by compiling just the head (bare expression)
- Test helper: compile_source(source, arena) chains lexer_lex -> parser_parse -> compiler_compile
- Compiler command dispatch: compiler__head_matches(head, name, len) checks if AST_LIT_STRING matches a builtin name
- compiler__compile_command dispatches known builtins (+, -, *, /, %) via if-chain with early returns
- compiler__compile_binary(c, args, opcode, line) compiles 2 args + emits opcode
- Unary negation: "-" with argc==1 emits OP_NEG; argc==2 emits OP_SUB
- VM__BINARY_NUMERIC_OP macro dispatches i32/f32 variants, returns VM_RUNTIME_ERROR on type mismatch
- OP_MOD is i32-only in VM; f32 operands produce VM_RUNTIME_ERROR
- Division by zero produces error-flagged value (VM_OK), not VM_RUNTIME_ERROR

- OP_PRINT: pops value, formats via print_fn, pushes JACL_NIL as return value
- Print formatting: error-flagged -> "<error>", nil -> "nil", bool -> "true"/"false", i32 -> %d, f32 -> %g, inline_string -> content
- Test print output: PrintCapture struct {buf[256], len} with capture_print callback set via vm.print_fn/vm.print_ctx

- VM API: VM struct in src/vm.c, vm_init(VM*, arena_t*), vm_exec(VM*, BytecodeChunk*)
- VMResult enum: VM_OK, VM_RUNTIME_ERROR, VM_STACK_OVERFLOW
- VM stack: JaclVal stack[256], stack_top is next free slot index
- VM has configurable print_fn + print_ctx, defaults to stdout via vm__default_print
- VM has arena_t* for environment allocations (passed to vm_init)
- Internal helpers: vm__push, vm__pop, vm__read_byte, vm__read_u16

- Environment: growable (name, value) pairs in VM, arena-allocated arrays
- vm_init pre-populates: "true" -> JACL_TRUE, "false" -> JACL_FALSE, "nil" -> JACL_NIL
- vm__env_set: linear scan for existing name, overwrite or append
- vm__env_get: linear scan, returns jacl_set_error(JACL_NIL) if not found
- Name comparison uses direct JaclVal == (inline strings with same content produce identical bit patterns)
- OP_DEF_GLOBAL: pops value, stores in env, pushes JACL_NIL as return
- OP_GET_GLOBAL: looks up name in env, pushes value or returns VM_RUNTIME_ERROR for undefined vars
- Compiler `def`: checks argc==2, args[0] must be AST_LIT_STRING, compiles value then emits OP_DEF_GLOBAL
- Compiler AST_VAR_REF: creates inline_string from name, emits OP_GET_GLOBAL

- Pipeline API: jacl_run(source, vm, arena) in src/vm.c
- jacl_run chains: lexer_lex -> parser_parse -> compiler_compile -> vm_exec
- Returns VM_RUNTIME_ERROR for parse/compile errors, sets vm->error_message

- VM error reporting: error_message (arena-allocated or static) and error_line fields on VM struct
- vm__set_error(vm, fmt, ...) for formatted error messages via vsnprintf + arena_alloc
- vm__type_name(val) returns "nil"/"bool"/"i32"/"f32"/"string"/"unknown" for error messages
- VM dispatch loop sets vm->error_line from chunk->lines[offset] at start of each iteration
- VM__BINARY_NUMERIC_OP macro takes third arg op_name for error messages
- CompileResult.error_message stores first compile error with source position ("line N, col N: message")
- compiler__error(c, line, col, message) accepts position and stores formatted error message
