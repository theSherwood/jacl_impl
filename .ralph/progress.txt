# Ralph Progress Log
Started: Sun Apr 20 2026
Feature: Operators as Macros

## Codebase Patterns
- Parser emits uniform AST: operators become [op lhs rhs] via parser__parse_cmd_expr()
- Bare words in command mode wrap to zero-arg commands: `x` becomes `[x]`
- Semantic rewriting (= → def, etc.) happens in compiler.c, not parser.c
- Tests in test_parser.c use setup()/teardown() pattern with tracked_allocator
- Parser tests use parse_expr() for single expressions, parse() for full source
- Prelude macros: add to src/prelude.jacl, build.sh auto-generates prelude_source.h
- MacroEntry.is_builtin = true marks prelude macros (user can override)
