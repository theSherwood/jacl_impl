## Codebase Patterns
- test/test_compiler.c directly calls internal compiler functions (like compiler__find_global_arity) — update test file when renaming internal helpers
- Build uses build.sh; results show "=== Results: N passed, M failed ===" at the end
- Pre-existing failures on main: rdoc, nfa_rdoc, nfa_cross (3 total after US-001)
- VM uses UNBOXED raw bits for i64/u64/f64 on the stack (typed arithmetic path); embed API uses BOXED heap objects. Shared struct helpers use ThreadHeap*=NULL for unboxed, non-NULL for boxed. Embed write functions must unbox 64-bit values before calling vm__struct_write_field.
- jacl.c unity build order: value.c → gc.c → ... → vm.c → gc_collect.c → runtime.c → embed.c. Shared helpers in vm.c are accessible by embed.c (defined earlier in the translation unit).
