## Codebase Patterns
- platform.h uses three-way conditional compilation: `#ifdef __EMSCRIPTEN__` / `#elif defined(_WIN32)` / `#else` (POSIX)
- Tests use `test_helpers.h` with ASSERT macros and return 1 for pass, 0 for fail
- build.sh entries with threads need explicit `-lpthread` flag in the extra_cflags field
- Thread tests use `THREAD_CREATE/THREAD_JOIN` from platform.h, `SLEEP_MILLISECONDS` for timing
- GC template defines follow pattern: `#define FOO_GC_ALLOC(t, sz) gc_alloc(gc__current_heap, (t), (sz))`
- sum_tree.h now uses GC allocation via STREE_GC_ALLOC macros (RC fully removed); rope.h ref/unref are no-ops
