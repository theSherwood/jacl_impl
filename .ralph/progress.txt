## Codebase Patterns
- Single-header convention: `#ifndef X_H` / `#define X_H` for declarations, `#ifdef X_IMPLEMENTATION` for implementation
- Arena allocator: zero-init `arena_t arena = {0}`, uses libc by default
- Test tracked allocator: `tracked_allocator` from `test/test_helpers.h`, plug into arena via `.allocator = tracked_allocator`
- Build system: `build.sh` with `TESTS=()` array entries formatted as `"path/test.c|name|optional_extra_cflags"`
- Compiler flags: `-Wall -Wextra -std=c99 -g`
- Relative includes from module dirs use `../` prefix (e.g., `#include "../arena/arena.h"`)
- Implementation language is C (C99)
- Existing modules: platform/ (atomics, threading), arena/ (bulk allocation), test/ (test harness), lexer/ (tokenizer), value/ (tagged value system)
- Value module: `value/value.h` is the single-header for 64-bit tagged values. Type tags are pre-shifted constants (e.g., `JACL_TAG_I32 = 0x02 << 56`). Flags occupy bits 63-61, type tag bits 60-56, payload bits 55-0.
- Test warnings from unused test_helpers.h static functions are expected and benign
- Value predicates: use `(v & JACL_TYPE_MASK) == JACL_TAG_XXX` to ignore flag bits
- Simple static inline functions go in the header declaration section, not the `#ifdef VALUE_IMPLEMENTATION` section
- Pointer packing: cast `(uint64_t)(uintptr_t)p & JACL_PAYLOAD_MASK`, extraction: `(void *)(uintptr_t)(v & JACL_PAYLOAD_MASK)`
- C99 compile-time assert: `typedef char name_[(cond) ? 1 : -1]` (no `_Static_assert` in C99)
- Inline string packing: bytes packed via `((uint64_t)(unsigned char)s[i]) << (i * 8)`, length determined by first null byte in 7-byte payload
- Arithmetic functions must be placed AFTER extractors in value.h (C99 requires forward declarations; extractors like `jacl_as_i32` must be defined before arithmetic functions that call them)
- INT32_MIN / -1 and INT32_MIN % -1 are undefined behavior in C99; guard with explicit checks
- Arithmetic pattern: error short-circuit first, then propagate flags, compute, apply flags to result
- f32 division by zero: follows IEEE 754 (returns inf/NaN), NOT error-flagged — unlike i32 which returns error-flagged zero
- Comparison pattern: same as arithmetic — error short-circuit, propagate flags, compute bool result, apply flags
- Equality (`jacl_eq`): compares `(v & (JACL_TYPE_MASK | JACL_PAYLOAD_MASK))` — type+payload, ignoring flags; cross-type always false

  - All flag operations preserve both the type tag (JACL_TYPE_MASK bits) and payload (JACL_PAYLOAD_MASK bits) exactly
  - Tests verify flags across all value types: nil, bool (true/false), i32, f32, string pointer, inline string
