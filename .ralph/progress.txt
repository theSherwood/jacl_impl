## Codebase Patterns
- Parser desugaring: `name = val` → `[def name val]`, `name : val` → `[mut name val]`, `name :: val` → `[set name val]`. Operator forms handled in `parser__parse_bare_command()`.
- New opcodes: add to enum in bytecode.c BEFORE OP_HALT, add name in `bytecode__opcode_name()`, add VM handler in vm.c dispatch switch, update test_bytecode.c enum value assertions.
- Compiler builtins: handled in `compiler__compile_command()` via `compiler__head_matches(head, "name", len)` pattern.
- AST_COMMAND for patterns: when `def [a b c] expr` is written in keyword form, `[a b c]` parses as AST_COMMAND with head=first-element, args=remaining-elements. Compiler detects and converts.
- Tests: e2e tests use `jacl_run()` with PrintCapture helper. Pattern: `run_capture(src, &cap)` returns VMResult, check cap.buf for output.
- Locals are stack positions: `compiler__add_local()` just records metadata, the value must already be on the stack at the right position.
- Mut locals use cells: OP_MAKE_CELL wraps top-of-stack, creating a mutable reference. Access via OP_GET_CELL_LOCAL/OP_SET_CELL_LOCAL.
- Globals (scope_depth==0): use OP_DEF_GLOBAL with name index constant. OP_DEF_GLOBAL pops value, pushes nil.
- OP_DESTRUCTURE_VEC encoding: `count (uint8), skip_mask (uint8)`. skip_mask bit i = wildcard at position i (not pushed).
- Compile errors return VM_RUNTIME_ERROR from jacl_run() — no separate VM_COMPILE_ERROR value exists.

## 2026-03-18 - US-001
- Implemented positional vector destructuring: `def [a b c] $v` and `[a b c] = $v`
- Files changed:

  - src/bytecode.c: Added OP_DESTRUCTURE_VEC opcode (pops vec, validates type+length, pushes N elements)

  - src/compiler.c: Added `compiler__compile_destructure_vec()` helper, destructuring branches in both def and mut paths (handles AST_DESTRUCTURE_VEC and AST_COMMAND patterns)
  - src/vm.c: Added OP_DESTRUCTURE_VEC handler with runtime type/length checks
  - test/test_destructure_vec.c: 11 e2e tests (basic operator/keyword, expr RHS, nested scope, mut, length mismatch error, non-vector error, global, single, strings, typed)
  - test/test_bytecode.c: Updated opcode enum value assertions
  - build.sh: Added test to runner
- **Learnings for future iterations:**
  - Mut destructuring for locals needs special handling: can't use OP_DESTRUCTURE_VEC directly because each element needs OP_MAKE_CELL wrapping. Solution: store vec as temp local (empty name), extract elements individually with OP_GET_LOCAL + OP_VEC_GET + OP_MAKE_CELL.
  - Global destructuring processes elements in reverse order (top-of-stack first), with OP_POP to discard intermediate nils from OP_DEF_GLOBAL.
  - Typed destructuring in operator form (`[i64 a, i64 b] = $v`) requires dedicated parser since commas aren't handled in bracket command parsing.
  - For keyword form (`def [a b c] $v`), the pattern parses as AST_COMMAND — compiler detects and converts by extracting names from head + args.
