## Struct Types — User-defined compound value types for JACL

Progress log for ralph/struct-types branch.

## Codebase Patterns
- Build and test with `bash build.sh` from project root
- JACL proc names must be <= 7 bytes (inline string limit). Use short names.
- `==` is the equality operator (not `=`)
- .jacl integration tests use `# mode: concurrent` and `# expect:` headers
- test files include `../src/jacl.c` directly (unity build pattern)
- Pre-existing compiler warnings in hamt.h, rrb_vec.h are expected — only check for new warnings
- GCHeader is 8 bytes: epoch(u32) + mark:1/gen:1/survive_count:2/_reserved:4 (bitfields) + obj_type(u8) + alloc_total(u16)
- When adding fields to WorkerThread, must update ALL test files' rt_test__init_no_threads helpers
- Bare `$var` in JACL is a value read (not a zero-arg call as of 16ebe58)
- CPS mode effective recursion limit ~65 iterations (VM_STACK_MAX=256)
- When adding new AST node types: must add explicit case in compiler__compile_node (no default), but analysis switches have default: cases
- realpath() available via platform.h (<stdlib.h>) — use for canonical path resolution in module system
- compiler__compile_module() is the entry point for compiling dependency modules; shares ModuleCache + ImportStack with importer
- Module exports are populated from compiler's global_arities after compilation, excluding underscore-prefixed names
- Typed proc syntax: `proc i64 add [i64 a i64 b]` — return type AFTER `proc`, not before
