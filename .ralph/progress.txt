## Codebase Patterns
- Unity build: src/jacl.c is the unity build entrypoint; it includes value.c, gc.c, gc_collect.c, vm.c, etc. in a specific order. jacl.c does NOT include jacl.h.
- Type duplication convention: jacl.h declares public types (GCHeader, JaclSyntax, SyntaxKind, etc.) for external consumers (tests). Unity build source files (gc.c) have their own parallel definitions. The two must stay byte-identical. This is the established pattern — don't try to "deduplicate" it.
- Test builds: test/ files include src/jacl.h and link against .build/libjacl.a. lib/ tests compile standalone.
- Running tests on macOS: stdout is fully buffered when not a TTY. Use `stdbuf -o0 -e0 timeout N .build/<test>` to see output when killed.
- Pre-existing broken tests (on HEAD f8d63e3): parser, e2e_struct_tramp, embed. Not related to macro work.
- VMFormatBuf usage: init with `VMFormatBuf buf = {0}; buf.arena = &arena;` — vm__fmt_ensure handles cap==0 by seeding to 128.
- build.sh takes --test=NAME for single-test filter; --clean clears .build.
- syntax_from_ast signature: JaclVal syntax_from_ast(AstNode *node, ThreadHeap *heap, JaclInternTable *intern). Returns JACL_NIL for NULL nodes or AST_ERROR.
- build.sh now auto-detects platform changes (macOS ↔ Linux) via .build/.platform stamp. All 84 tests (lib/ + test/) should pass on a clean build.
- syntax_to_ast signature: AstNode *syntax_to_ast(JaclVal syn_val, arena_t *arena). Returns NULL for JACL_NIL or non-syntax values.
- For string round-trip: use jacl_string_byte_len() + jacl_string_data() to copy JaclVal strings into arena memory.
- Pretty-printer does NOT always re-emit quotes: "hello" parses as AST_LIT_STRING but prints as bare `hello`. Compare against ast_pretty_print of the original, not the source text.
- TokenType and AstNodeType enums are ALSO duplicated in jacl.h (like SyntaxKind). When adding a new token or AST node type, update BOTH the source .c file AND jacl.h, keeping them byte-identical.
- When adding a new keyword token: update (1) TokenType enum in lexer.c AND jacl.h, (2) keyword switch table in lexer.c, (3) keyword-as-atom case lists in parser.c (3 places: parser__parse_atom, parser__parse_cmd_operand, parser__parse_cmd_operand default switch), (4) top-level dispatch in parser_parse.
- When adding a new AST node type: update (1) AstNodeType enum in ast.c AND jacl.h, (2) AstNode union in ast.c AND jacl.h, (3) pretty-printer in ast.c, (4) syntax_from_ast and syntax_to_ast in syntax.c if convertible, (5) SyntaxKind enum in gc.c AND jacl.h if adding a syntax kind, (6) GC tracing in gc_collect.c, (7) compiler.c main switch.
